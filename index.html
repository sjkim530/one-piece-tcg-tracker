Rows marked ? are Extra and Premium Boosters, whose per-pack rarity structure Bandai has never published. Their box and pack counts are confirmed; the rarity split is inferred from each set's own card pool, so read those returns as rough.
Return is expected sealed value against box price, before you sell anything. It is an average across infinite boxes — not what your box will do. A set can show +30% and still brick nine boxes out of ten if Top-5 share is high.

Supply signal — cheap copies drying up

Card Set Market Floor Mid Floor / market Supply Call
There is no free eBay listing-count or PSA population feed, so this is not TCGQuant's exact input. What every card does have is a lowest listing and a recent sold average. A BARGAIN is a card listed in the cheapest 10% for its own price range — you can buy it meaningfully under what it has been selling for. Thresholds are per price band, measured live from the catalogue, because the floor-to-market ratio climbs with price: among $500+ cards the median is already listed above market, so one fixed cut-off would just select expensive cards. A floor above market is not bullish on its own — market price is a lagging sold average, so it can mean one overpriced listing on a card nobody trades. TCGplayer publishes no price history, so nothing here confirms which way a price is moving. Check the Mid column too: a floor far below it is a single cheap seller, which may simply be a damaged copy.

Data source

Card data and prices come from TCGplayer via tcgcsv.com, which refuses browser requests, so a small Cloudflare Worker fetches on the app's behalf. Deploy worker/worker.js and paste its URL here. It is stored in this browser only and never committed — see DEPLOY.md.

Box prices

Box prices are live TCGplayer market prices in v2. Anything you edit turns gold, overrides the live price and is saved to this browser — put in what you actually pay. Only sets with no sealed listing at all (sold out, or not yet released) still show EST and fall back to an estimate.

Pull rates

Bandai publishes nothing. Community tables disagree with each other and most do not even sum to a real box. These do. Adjust them to match what you actually pull — every number in the app moves with them.

Pick a profile to set every set of that type at once, or pick a single set to override just that one — sets marked ✎ have their own rates. Slot pool sizes are already per-set everywhere, so a set with 5 Manga Rares gives each one a fifth of the odds without you doing anything.

Data

Card data and English market prices from tcgcsv.com, sourced from TCGplayer. Pull rates are community estimates, not official Bandai figures — treat every number here as a model, not a promise. Built for ripping, not for financial advice.
